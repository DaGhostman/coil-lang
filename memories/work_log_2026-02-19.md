### Syntax Supported
```zero
fn identity<T>(T x) -> T {
    return x;
}

fn main() {
    let x: int = identity::<int>(42);  // turbofish syntax
    let y: int = identity(100);       // type inference
}
```

### Notes
- Generics implemented using monomorphisation approach (compile-time instantiation)
- Type bounds infrastructure is in place but not yet enforced at runtime
- Generic struct/interface support not yet implemented (functions only)
